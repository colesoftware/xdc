# XDC — Marketing & Documentation Assets

This repository hosts images and documentation assets for the 
Visual Studio Code extension for [Cole Software's](https://colesoft.com) **Z/XDC**
mainframe debugger. It exists so those assets can be served over a stable,
public URL (via [jsDelivr](https://www.jsdelivr.com/)) for the extension's
Marketplace listing.

**This repository does not contain the extension's source code.** It holds
screenshots and related assets only.

## Get the extension

- **Visual Studio Marketplace:** https://marketplace.visualstudio.com/items?itemName=colesoft-marketing.code-xdc
- **Cole Software:** https://colesoft.com

## About Z/XDC

Z/XDC is Cole Software's interactive debugger for z/OS. The XDC extension
brings its debugging capabilities into Visual Studio Code, letting you attach to
live debug sessions and step through HLASM programs with a modern, source-aware UI.
